# 登录失败与会话过期

登录失败、账号被临时锁定、Google 登录跳转异常、使用中被登出（401）时，按本页顺序排查即可恢复；多数问题通过核对错误码、等待锁定解除或重新登录就能解决。

## 适用范围

- **适用角色**：全部六类角色——`system_admin`、`org_admin`、`project_manager`、`member`、`external_collaborator`、`readonly_observer`（登录是进入系统的前提，不区分角色）；组织管理员处理成员登录问题时也参考本页。
- **所需权限**：无需任何权限；登录页 `/login` 是唯一公开页面。

## 开始之前

- **会话机制**：登录后签发 JWT（access / refresh）；任一 API 返回 401 时，前端会静默刷新一次并重放原请求，刷新仍失败才登出并跳回 `/login?next=<原路径>`。会话保存在 `sessionStorage`（key `aiproj-auth-session`），**关闭标签页即失效**，没有「记住我」能力。
- **准备信息**：账号、所在组织、完整的错误提示文案、出错操作路径、发生时间。
- 安全提示：排查全程不要向任何人提供密码或令牌；帮助中心也不收集密钥。

## 症状识别

- **登录失败**：输入账号密码后出现红色错误条，无法进入系统。
- **账号锁定**：连续输错后被提示「登录尝试过多」，即使密码正确也拒绝登录。
- **会话过期**：使用中被登出，或接口持续返回 401。
- **Google 登录跳转失败**：点「使用 Google 登录」后无响应、报错或弹窗被拦截。
- **组织选择异常**：登录后看不到应属组织，或切换不到目标组织。

## 排查步骤

### 步骤 1：核对账号、密码与账号状态

1. 确认邮箱无前后空格、大小写与输入法全角字符干扰；密码无多余空格。
2. 确认账号未被停用：停用账号登录会提示「账户已被禁用，请联系管理员」，需找组织管理员确认成员状态。

### 步骤 2：按错误提示与错误码定位

登录失败时页面顶部会出现红色错误条，文案与后端错误码一一对应：

| 错误码                | HTTP | 页面提示                                                                                           | 含义与处理                                       |
| --------------------- | ---- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `INVALID_CREDENTIALS` | 401  | 「邮箱或密码不正确，请重新检查。」                                                                 | 凭证错误；重试前先确认输入，避免连续重试触发锁定 |
| `AUTH_REQUIRED`       | 401  | 「邮箱或密码不正确，请重新检查。」                                                                 | 登录请求本身未通过认证，按凭证错误处理           |
| `ACCOUNT_LOCKED`      | 401  | 「登录尝试过多，请稍后再试。」（后端消息：「登录失败次数过多，账户已临时锁定，请 30 分钟后再试」） | 账号已临时锁定，见步骤 3                         |
| `ACCOUNT_INACTIVE`    | 401  | 「账户已被禁用，请联系管理员。」                                                                   | 账号被停用，联系组织管理员                       |
| 限流（接口级）        | 429  | 网络类兜底提示                                                                                     | 短时间内请求过多触发登录接口限流，等待片刻后重试 |
| 其他（网络 / 500）    | —    | 「暂时无法登录，请检查网络后重试。」                                                               | 网络或服务问题，见步骤 4                         |

> 页面错误条只展示服务端返回的文案；「权限判定以服务端为准」同样适用于登录——**前端文案只是引导，不代表背后具体原因**。

### 步骤 3：检查账号临时锁定

- 锁定规则：同一 `email（小写）+ IP` 连续失败 **5 次**后锁定 **30 分钟**；锁定期内**即使凭证正确也会被拒绝**（`ACCOUNT_LOCKED`）。
- 处理：等待 30 分钟后再试；不要反复提交，否则会持续刷新锁定窗口。
- 多设备/多浏览器同时重试也会计入同一 `email + IP` 的失败计数，先停下来核对密码来源。

### 步骤 4：检查会话与网络

1. 收到 401 或「会话过期」时，刷新页面；若刷新后仍被登出，说明 refresh 链路失败，重新登录即可。
2. 确认设备时间与服务器时间同步（时间偏差会导致令牌失效判断异常），检查代理 / VPN 是否拦截请求。
3. 本机 `pnpm dev` 环境：确认后端已启动（默认 `http://localhost:3333`，可用 `curl http://localhost:3333/api/v1/health/ready` 验证）；容器部署环境确认 `docker compose ps` 中 backend / edge 健康。
4. 登录成功后的回跳地址受安全限制：`?next=` 只接受站内绝对路径，外部地址、`//` 开头的协议相对地址和 `/login` 自身都会回退到 `/dashboard`——「跳转后没有回到原页面」属预期安全行为。

### 步骤 5：排查 Google 登录

1. **未配置态**：按钮下方出现「Google 登录尚未配置：<缺失键名>。」（如缺少 `AIPROJ_GOOGLE_OAUTH_SECRET_FILE`、`GOOGLE_AUTH_SUCCESS_REDIRECT_URL` 等环境变量）。这是**部署配置缺失**，不是故障；请联系部署方配置后重启后端。配置预检的状态（missing_file / unreadable_file / invalid_json / invalid_client_shape / redirect_not_configured）各有对应中文提示，例如「Google 登录未配置：回调地址未登记，请在 Google Console 登记 {origin}/api/v1/auth/google/callback。」
2. **弹窗被拦截**：允许浏览器弹窗、关闭广告拦截插件后重试；仍失败可先用账号密码登录，判断是否为 Google 授权链路问题。
3. **回调错误码**：Google 授权回跳失败时按 `?google_error=` 映射展示文案：

| 回跳错误码              | 页面提示                                   |
| ----------------------- | ------------------------------------------ |
| `access_denied`         | 「已取消 Google 授权。」                   |
| `invalid_state`         | 「Google 登录请求已失效，请重新登录。」    |
| `token_exchange_failed` | 「Google 登录暂时不可用，请稍后再试。」    |
| `google_api_error`      | 「读取 Google 账号信息失败，请稍后再试。」 |
| `account_inactive`      | 「账户已被禁用，请联系管理员。」           |
| `not_configured`        | 「Google 登录未配置完整。」                |
| `google_login_failed`   | 「Google 登录失败，请重试。」              |

4. 登录接口同样受限流保护：连续快速重试会触发接口级限流（HTTP 429 类表现），等待片刻再试。

## 修复与恢复

| 症状                | 直接修复动作                                                             |
| ------------------- | ------------------------------------------------------------------------ |
| 凭证错误            | 核对并重置密码后重新登录；重置密码遵循 8–32 位且含大小写字母与数字的策略 |
| `ACCOUNT_LOCKED`    | 停止重试，等待 30 分钟锁定解除后再登录                                   |
| `ACCOUNT_INACTIVE`  | 联系组织管理员启用账号                                                   |
| 会话过期 / 频繁 401 | 重新登录获取新会话；长期反复过期需检查设备时间同步与代理                 |
| Google 未配置       | 由部署方补齐 `AIPROJ_GOOGLE_OAUTH_*` 环境变量并重启后端                  |
| 429 / 网络类提示    | 停止快速重试，检查网络与代理，稍后重试                                   |

## 升级与收集信息

仍失败时，记录以下信息反馈到帮助中心「故障排查」：

- **request id**：错误信息或浏览器开发者工具网络面板中请求的标识（后端审计也以它关联）。
- 账号（不提供密码）、所属组织、出错时间与完整错误文案、复现路径。
- Google 登录场景：说明是配置缺失提示还是回跳错误码（`google_error=` 的取值）。

## 验证结果

- 你能正常登录并进入正确的组织（或被正确回跳到登录前目标页）。
- 锁定解除后能正常登录；会话过期后重新登录成功。
- 登录页不再出现错误提示；Google 登录按钮按配置状态正确显示。

## 常见问题

**症状：登录页一直转圈或提交无反应。**
可能原因：网络或浏览器扩展拦截请求。
排查与修复：关闭扩展、刷新页面；本机环境确认前后端已启动。

**症状：提示「登录尝试过多」但密码是对的。**
可能原因：此前同一 `email + IP` 已累计失败 5 次进入锁定。
排查与修复：等待 30 分钟；期间不要再提交，也不要换浏览器反复试同一账号。

**症状：登录成功但看不到任何组织/项目。**
可能原因：账号尚未加入组织的成员列表，或登录后组织选择错误。
排查与修复：核对右上角组织；联系组织管理员添加成员；参考「项目加载失败与列表为空」。

**症状：Google 登录按钮置灰并提示「尚未配置」。**
可能原因：环境变量缺失是部署配置项，不是账号问题。
排查与修复：联系部署方配置 `AIPROJ_GOOGLE_OAUTH_*`；配置完成前用账号密码登录。

**症状：收到 401 非常频繁。**
可能原因：refresh 链路失败、令牌无法续期或时间不同步。
排查与修复：重新登录，校准设备时间，检查代理配置。

## 安全与限制

- **登录锁定是安全边界**：5 次失败锁 30 分钟，锁定期内正确凭证也拒绝，请勿尝试用自动化工具「测试密码」。
- **组织隔离**：登录身份不等于管理权限；角色与权限以服务端判定为准。
- **会话**：会话仅存于 `sessionStorage`，关闭标签页即失效；不存在「记住我」选项。
- **开发环境专属**：登录页的「本机开发账号」提示只在 `development` 环境渲染，生产环境不会出现；演示账号 `password123` 由种子直接写入，不满足注册密码策略，不要用于注册。

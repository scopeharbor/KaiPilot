# Copilot 不可用

Copilot 无法打开、无法回答或只能给出固定演示答复时，绝大多数原因集中在 **AI 连接未配置、可用性状态受限、余额与模型名** 四类；按本页识别状态并排查即可恢复。

## 适用范围

- **适用角色**：所有使用 Copilot 的成员（`member`、`project_manager`、`org_admin`、`system_admin` 等均可提问）；**组织管理员（org_admin）负责检查与修复 AI 连接配置**（管理连接需要 `ai:connection:manage`，当前为 org_admin / project_manager / system_admin）。
- **所需权限**：提问本身由后端按「组织成员资格 + 可用性评估」判定；不具备条件时入口会给出低敏提示（见症状识别）。
- **适用版本**：free / team / enterprise（连接配置按组织独立，与套餐无关）。

## 开始之前

- **AI 能力依赖「设置 → AI 连接」中的模型连接**：连接必须启用、已保存密钥、勾选对话类能力（`chat`），Copilot 才能走真实模型通道。
- **准备信息**：入口状态标签文案、报错画面（截图或原文）、发生时间、使用的功能入口（侧栏面板 / 工作台卡片）。

## 症状识别

Copilot 入口（工作台 `AI Copilot` 卡片与顶栏 Sparkles 按钮）有一个可用性状态机，状态标签包括：

| 状态标签                      | 含义                                                               |
| ----------------------------- | ------------------------------------------------------------------ |
| 正在检查可用性 / 正在刷新状态 | readiness 请求进行中，短暂现象                                     |
| 可用                          | 可以正常提问                                                       |
| 部分可用                      | 部分能力受限（如最近会话读不到、快捷建议不可用），核心问答不受影响 |
| 暂不可用                      | 当前无法使用 Copilot                                               |
| 无权限                        | 当前账号没有使用 Copilot 的权限                                    |
| 需要刷新                      | 可用工具清单需刷新后才能使用                                       |
| 演示模式                      | 回答来自固定示例，不会读写任何真实数据                             |

入口下方会逐条列出低敏原因说明，常见文案：
「当前账号还没有可用的组织，请先加入或选择一个组织」/「当前账号没有使用 Copilot 的权限」/「当前作用域不可用，请切换到你有权限的范围」/「暂时无法确认 Copilot 是否可用，可稍后重试」/「状态检查失败，可稍后重试」。

打开面板后如看到底部标注「演示模式：回合通道未接入；对话不会保存或修改任何项目数据」，说明当前处于**演示回退**而非真实模型通道。

## 排查步骤

### 步骤 1：核对 AI 连接配置（最常见原因）

进入「设置 → AI 连接」（`/settings/ai-connections`，需 `ai:connection:manage` 或 `ai:trigger`）：

1. **连接是否为空**：列表空态「尚无连接,点「新增连接」添加你的第一个 AI 模型。」——没有任何连接时 Copilot 无法走真实模型通道。
2. **连接是否启用**：卡片带「(已停用)」标记或模型 chip 显示停用时，先点「启用」。
3. **是否已保存密钥**：卡片显示「未设 key」时，编辑连接填入有效 API Key（密钥只存后端加密服务，页面不会回显明文）。
4. **模型能力是否匹配**：Copilot 对话需要模型具备 `chat`（聊天/问答）能力；只勾了 OCR 等能力的模型不能用于对话。
5. 点「测试」：返回「已连通 · {latency}ms · {model} · Token …」即连接可用；失败按错误信息核对 Base URL、模型名与密钥。

> 常见误解：`/ai-create` 的模型选择器显示「未配置草案模型，使用系统兜底」，Copilot 侧栏也可能在**未配置连接**时以演示/受限状态运行——这都说明组织还没有可用的活跃连接，先完成上面的配置。

### 步骤 2：核对账号与组织资格

1. 提示「当前账号还没有可用的组织」：账号未加入任何组织或组织选择不正确；请组织管理员添加成员后重试。
2. 提示「当前账号没有使用 Copilot 的权限」：当前角色不具备使用资格；组织隔离下，跨组织账号不会获得任何能力快照（只显示低敏提示，不显示错误细节）。
3. 切换组织或刷新页面后仍异常：重新登录一次，让角色快照重新加载。

### 步骤 3：核对余额与配额

- 模型供应商账户余额/配额不足时，请求会被供应商拒绝（常见表现为 401/429 或超时类错误）。
- 处理：联系组织管理员检查供应商账户；在「AI 连接」中切换到余额充足的连接，或配置备用连接后重试。
- 组织级预算：若组织配置了编译器预算，超限时会出现「预算已超限 / 预算阻断」类提示（阻断无绕过按钮，需组织管理员调整）。

### 步骤 4：核对模型名与网络

1. 模型不存在（404 类表现）：模型名与供应商目录不一致。进入连接编辑，对照供应商文档使用准确模型标识；可通过 models.dev 目录搜索（如「OpenAI、火山引擎、腾讯云、DeepSeek…」）核对。
2. 网络：确认代理/防火墙未拦截到模型供应商端点的长连接；本机环境确认后端已启动。
3. 网页搜索相关：若报「组织尚未启用网页搜索」或「今日组织搜索额度已用完」，这是可选工具的独立门控，**不影响**纯内部问答；参考「外部网页搜索」文章。

### 步骤 5：识别演示模式与真实通道

- 演示模式是**显式声明 + 显式进入**的：入口卡片会写明「当前是本机演示，回答来自固定示例，不会读写任何真实数据。」并提供「返回生产通道」按钮。
- 生产通道出错**不会**自动静默切换到演示；如果看到「演示模式：回合通道未接入」，说明宿主（本机演示部署）未接入回合通道，属该部署形态的既定状态。
- 动作类能力：当前所有动作卡片显示「预览不可用：动作通道尚未接入，不会自动执行任何修改。」——这是产品现状，不是故障，也不意味着 Copilot「坏了」。

## 修复与恢复

| 症状                           | 直接修复动作                                                        |
| ------------------------------ | ------------------------------------------------------------------- |
| 无任何连接 / 未启用 / 未设 key | 在「AI 连接」新增或启用连接，填入密钥并勾选 `chat` 能力             |
| 测试连接失败（401/404/超时）   | 核对密钥、Base URL、模型名；必要时换连接                            |
| 提示无权限 / 无组织            | 加入或切换组织；联系组织管理员检查角色                              |
| 余额或配额不足                 | 充值或切换备用连接；联系组织管理员检查预算                          |
| 演示模式 / 回合通道未接入      | 确认该部署是否声明了演示能力；生产部署应接入回合通道后恢复真实问答  |
| 改完连接仍报错                 | 确认默认/启用连接已更新，刷新页面后重试；仍失败记录 request id 升级 |

## 升级与收集信息

仍失败时，记录以下信息反馈到帮助中心「AI 能力」：

- **request id** 与报错原文（或入口状态标签截图）。
- 使用的功能入口（工作台卡片 / 侧栏）、发生时间。
- 组织管理员配合提供：AI 连接配置摘要（连接数、启用状态、模型名，**不要粘贴密钥**）、供应商余额状态。

## 验证结果

- 入口状态变为「可用」；侧栏底部显示「已接入回合通道：AI 只给建议，任何修改仍需你在预览中确认。」
- 提交问题后能收到流式回答；引用外部资料时带「外部来源带引用标记，仅供参考」说明。
- 任何回答都未在你确认前修改或写入项目数据。

## 常见问题

**症状：Copilot 提示「模型不存在」。**
可能原因：模型名与供应商目录不一致，或能力不匹配。
排查与修复：使用准确模型名并核对 `chat` 能力勾选；参考「配置 AI 连接」常见问题。

**症状：入口显示「部分可用」但能提问。**
可能原因：最近会话、快捷建议或工具清单暂时读取不到，核心问答不受影响。
排查与修复：可直接开始新对话；快捷建议不可用时直接输入问题即可。

**症状：只能收到固定示例答复。**
可能原因：处于演示模式（「回答来自固定示例」）或回合通道未接入。
排查与修复：确认是否通过「查看本机演示（不写入任何数据）」进入；点「返回生产通道」；生产部署需接入回合通道。

**症状：AI 连接页提示「没有 AI 连接管理权限」。**
可能原因：当前角色无 `ai:connection:manage`。
排查与修复：请组织管理员配置连接；有 `ai:trigger` 的成员可以打开页面查看但无管理入口（不同权限看到不同形态）。

**症状：改完连接 Copilot 仍报错。**
可能原因：默认连接未更新或页面缓存。
排查与修复：确认启用连接已保存，刷新页面后重试。

## 安全与限制

- **AI 只建议、不自动执行**：Copilot 回答仅作参考，任何修改都需要你在预览中确认后才会生效；动作通道当前未接入。
- 密钥只保存在后端加密服务；排查过程中不在文档、聊天或日志中粘贴密钥。
- 组织隔离：连接与能力快照按组织独立；跨组织不返回任何能力细节。
- 网页搜索是独立可选工具：默认关闭，需组织启用 + 每次提问显式同意才会联网，且「真实 provider 接入需单独授权」。

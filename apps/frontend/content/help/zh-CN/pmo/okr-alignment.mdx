# OKR 能力现状与入口

本文说明组织 OKR 能力在**当前界面**的真实边界：哪些页面存在、能看什么、哪里不能操作、写能力现在从哪里获得。OKR 由三个页面构成——OKR 层级管理、OKR Dashboard、OKR 级联与对齐——它们共享同一套后端能力，但前端入口与可用性各不相同。

## 适用范围

- **适用角色**：查看类能力覆盖 `org:view` / `portfolio:view` 任一即可；全部写操作（创建周期/目标/KR、创建级联计划、管理对齐关系、AI 级联建议确认）后端要求 `org:manage`。
- **所需权限**：查看 = `org:view` / `org:manage` / `portfolio:view` 任一；写 = `org:manage`。
- **适用版本**：free / team / enterprise。
- **进入路径**：三个页面均无侧边栏/命令面板/卡片入口，只能直接输入 URL（见下文各页）。

## 背景：OKR 与战略执行的关系

OKR（目标与关键结果）是组织级目标体系：周期（Cycle）→ 目标（Objective）→ 关键结果（Key Result），支持组织/团队/项目三种范围。目标层级关系与状态是三个页面的共同数据底座：

| 层级     | 说明                                        | 状态取值                             |
| -------- | ------------------------------------------- | ------------------------------------ |
| 周期     | OKR 的时间容器（如年度/季度）               | 草稿 / 进行中 / 已暂停 / 已完成      |
| 目标     | 周期内的战略目标，带范围与负责人            | 草稿 / 活跃 / 暂停 / 已完成 / 已归档 |
| 关键结果 | 目标的可量化结果，记录当前值/目标值与置信度 | 随目标状态                           |

战略执行驾驶舱把 OKR 目标与底层项目执行映射到一张只读矩阵，是实现「战略 → 执行」闭环的查看入口。本文的三个页面是 OKR 数据的查看与操作面。

## 三个页面现状总览

| 页面           | 路由                           | 前端可用性                                                       | 后端权限口径                                                              |
| -------------- | ------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------- |
| OKR 层级管理   | `/organization/okrs`           | 界面存在；**当前未接通组织上下文，恒显示空态**                   | 查看 okr_policy：组织可见 + `org:view`/`org:manage`/`portfolio:view` 任一 |
| OKR Dashboard  | `/organization/okrs/dashboard` | 界面存在；**当前 UI 仅系统管理员可进入**，其余角色显示无权限提示 | 后端同 okr_policy（org:view/portfolio:view 任一即可）                     |
| OKR 级联与对齐 | `/okr-alignment`               | 界面存在；**当前未接通组织上下文，页面无数据**                   | 查看同上；写（级联计划/关系/AI 建议确认）需 `org:manage`                  |

> 说明：以下「页面结构」描述的是页面实现的功能与文案；「当前可用性」如实标注了你现在实际能看到什么。

## 页面结构

### OKR 层级管理（/organization/okrs）

- 标题「OKR 层级管理」，顶部三个下拉：**周期**（`全部周期` + 周期标题列表）、**范围**（`全部范围/组织/团队/项目`）、**状态**（`全部状态/草稿/活跃/暂停/已完成`）。
- 顶部 meta：「共 {N} 个节点 · 最大深度 {N}」+「已截断」；amber 警告区展示 meta.warnings。
- 目标树：可展开/折叠节点，状态徽标（草稿灰/活跃绿/暂停琥珀/已完成蓝/已归档红）、范围标签、置信度进度（`{●◐○} {progress}%`，信心高/中/低）、「{N} KR」；展开后 KR 行显示圆点 + 标题 + `{currentValue}/{targetValue}` + 置信度；默认展开到第 2 层。
- 空态：「暂无 OKR 数据。请先创建 OKR 周期和目标。」
- **当前可用性**：由于组织上下文未接通，页面恒显示空态；树形查看、创建/编辑 OKR 均无法在当前界面完成——创建周期/目标/KR 等写接口仅通过 API 提供（需要 `org:manage`），页面暂无创建入口。

### OKR Dashboard（/organization/okrs/dashboard）

- 顶栏筛选：**周期**（默认「当前活跃周期」）、**范围**（全部/组织/团队/项目/个人）、**状态**（全部/进行中/已暂停/已完成）。
- 周期上下文头：周期标题 + 状态徽标 +「已过 {N}%」+「剩余 {N} 天」。
- 内容区：KPI 条（目标总数/进行中/已完成/风险目标等，脱敏值显示 `--` +「数据不可见」）、进度/状态分布双卡、关注项、对齐健康度、证据新鲜度、数据源新鲜度、进度回流条与警告列表。
- **当前可用性**：前端以 `okr:view` 做角色门控，而该权限当前未授予任何内置角色——除系统管理员（super admin 短路）外，所有角色都会看到「您没有 OKR Dashboard 访问权限，请联系管理员申请。」；后端实际口径为组织可见 + `org:view`/`portfolio:view` 任一。即：**当前 UI 仅系统管理员可进入，后端授权口径更宽**。该页面只读，不提供写操作。

### OKR 级联与对齐（/okr-alignment)

- 头部：周期下拉 + 范围下拉 + 「AI 级联建议」按钮（无周期时禁用）。
- **Tab 1 级联计划**：`新建级联计划`（需先选周期）；计划列表行显示标题、「状态: {status} · 覆盖: {N} 项」、「{N} 个警告」与创建日期。详情抽屉支持全选、「{sel}/{total} 已选」、确认所选（primary）/驳回所选（可填驳回原因）。
- **Tab 2 关系矩阵**：表头 目标/范围/状态/健康度/关系/父对齐/子数量/操作；受限行带 🔒「部分数据因权限限制不可见，已在表中标记。」；健康度徽标（健康/需关注/风险/不可用 + 分数 + ⚠警告）；关系列（依赖/贡献/支持/冲突/重复 → 目标 ID，取前 3 条）。
- **Tab 3 健康仪表盘**：汇总卡 总计/健康/需关注/风险/不可用；每行等级徽标 + 标题 +「评分: {N}/100 · 版本: {v}」+ ⚠警告 +「证据新鲜度: 已过期/新鲜（更新于 {日期}）」（≥80 绿 / 50–79 琥珀 / <50 红）。
- **AI 级联建议面板**：琥珀徽标「⚠ 仅预览 — AI 建议不会自动落库」；输入「源目标 ID (0 = 全部)」与「深度」(1–5)；蓝色提示「AI 生成的级联建议仅供参考。所有建议需要您审核确认后才会创建为正式 OKR 目标。此面板仅作预览用途，不会自动修改任何数据。」；候选列表显示「建议的级联目标 ({n})」标题 + 范围 + `置信度: 低/中/高`。
- **当前可用性**：与层级管理页相同，组织上下文未接通，页面无数据；「新建级联计划」在无矩阵数据时点击无效。创建级联计划、确认/驳回级联项、管理对齐关系、确认 AI 建议落库等写操作均为后端 API 能力（需 `org:manage`），当前界面未提供可用的完整操作闭环；AI 级联建议只做预览展示，不会自动修改任何数据。

## 操作步骤：确认当前可用入口

1. **确认你的权限口径**：查看 OKR 页面前，确认自己拥有 `org:view` / `portfolio:view` 之一；需要写能力时确认 `org:manage`（组织管理员）。
2. **尝试打开页面**：分别输入 `/organization/okrs`、`/organization/okrs/dashboard`、`/okr-alignment`。
3. **对照本文的「当前可用性」**：层级管理与级联页当前显示空态，属已知现状（组织上下文未接通），不代表数据不存在；Dashboard 页非系统管理员将看到无权限提示。
4. **需要写能力时**：通过 API 使用创建周期/目标/KR 或级联管理接口（需 `org:manage`），或在产品版本更新后重新检查界面入口。

## 验证结果

- 你能说出三个页面的当前可用状态与权限口径（哪些只读、哪些仅系统管理员可进、哪些无 UI 入口）。
- 你能明确指出「AI 级联建议仅预览、不会自动落库」的边界。
- 你知道写能力（创建周期/目标/KR、级联确认）当前通过 API 提供，而非界面按钮。

## 常见问题

**症状：OKR 页面打开后是空态。**
可能原因：组织上下文未接通（页面已知现状），或确实没有 OKR 数据。
检查：是否由组织管理员通过 API 创建了周期与目标。
修复：先通过 API（`org:manage`）创建周期/目标后，再回到页面查看；仍为空态时记录页面 URL 与 request id 反馈支持。

**症状：OKR Dashboard 提示「您没有 OKR Dashboard 访问权限」。**
可能原因：前端角色门控 `okr:view` 当前未授予任何内置角色（仅系统管理员可进入 UI）。
检查：是否为系统管理员账号。
修复：用系统管理员账号查看；后端口径（org:view/portfolio:view）与前端不同，属产品已知现状。

**症状：点「AI 级联建议」没有结果或没有落库。**
可能原因：无周期数据，或面板仅预览、确认流程未接通（AI 只建议、不自动执行）。
检查：是否已选择周期；候选列表中是否有「建议的级联目标」。
修复：AI 建议需要你审核确认后才会创建为正式 OKR 目标；当前界面未提供完整确认闭环，请通过 API 完成确认（`org:manage`）。

**症状：找不到 OKR 的导航入口。**
可能原因：三个页面均无侧边栏/卡片入口，只能 URL 直达。
检查：浏览器地址栏。
修复：直接输入本文给出的路由（组织上下文需已切换）。

## 安全与限制

- **AI 只建议、不自动执行**：AI 级联建议面板明确标注「仅预览 — AI 建议不会自动落库」；任何 OKR 写操作都需要人工确认（`org:manage`）。
- **写能力边界**：创建周期/目标/KR、级联计划创建与确认、关系管理均为 API 层能力，当前界面无创建入口。
- **角色门控现状**：OKR Dashboard 前端仅系统管理员可进入（`okr:view` 未授予内置角色）；后端口径为 `org:view`/`portfolio:view`。
- **组织隔离**：所有 OKR 数据按组织隔离；跨组织不可见，受限目标在矩阵中以 🔒 标记。
- **数字边界**：级联建议深度 1–5；源目标 ID 0 表示全部目标。

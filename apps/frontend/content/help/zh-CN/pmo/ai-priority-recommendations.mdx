# PMO AI 优先级推荐

PMO AI 优先级推荐（`/pmo/ai-priority-recommendations`）是组合层面的「AI 辅助优先级关注队列」：它基于**确定性评分**（与优先级评分同一模型）生成推荐草案，帮助你按严重度快速扫过「哪些项目值得优先关注」，并用 AI 生成可读的推荐理由草稿。页面副标题写得很清楚：**「AI 辅助优先级关注队列——基于确定性评分的推荐草案，所有建议需人工审查」**——推荐不是决定，只有人才能采纳。

## 适用范围

- **适用角色**：`portfolio:view` 即可查看页面（后端策略回退到 `portfolio:view`；六种规范角色均授予）。
- **所需权限**：`portfolio:view`。
- **适用版本**：free / team / enterprise。
- **进入路径**：当前页面无主导航入口，请直接输入 URL：`https://<你的域名>/pmo/ai-priority-recommendations`。

## 开始之前

- 推荐队列没有种子数据：全新环境显示空态「当前没有需要关注的推荐」+「所有项目状态良好，或尚未刷新推荐。点击右上角"刷新推荐"更新。」
- 记住边界：推荐状态（新推荐/审查中/已采纳……）与 AI 理由都只是决策辅助素材；**采纳与否由人决定，AI 不会自动执行任何操作**。

## 页面结构

### 头部与摘要 KPI

- 标题「PMO AI 优先级推荐」+ 副标题（见上文）+ 右上 **「刷新推荐」** 按钮（点击后转圈，重新拉取推荐）。
- 摘要 KPI 八张卡：`总计 / 严重 / 高 / 待处理 / 审查中 / 已采纳 / 已过期 / AI 理由`；严重 > 0 红底、高 > 0 橙底、待处理蓝底、AI 理由 > 0 绿底。

### 过滤器

- **状态**：全部状态 / 新推荐 / 审查中 / 已采纳 / 已忽略。
- **严重度**：全部严重度 / 严重 / 高 / 中 / 低。
- 右侧显示「共 N 条推荐」。

### 推荐卡片

每张推荐卡包含：

| 元素            | 说明                                                            |
| --------------- | --------------------------------------------------------------- |
| 严重度圆图标    | 按严重度着色                                                    |
| 标题 + 状态徽标 | 新推荐 / 审查中 / 已采纳 / 已忽略 / 稍后处理 / 已转换 / 已过期  |
| 数据过期徽标    | 数据新鲜度不足时显示                                            |
| 摘要            | 两行摘要文本                                                    |
| AI 状态徽标     | 无 AI / 生成中... / AI 理由可用 / AI 过期 / AI 失败 / AI 不可用 |
| 评分            | 等宽字体分数（确定性评分）                                      |
| 项目名          | 所属项目                                                        |

过期推荐整卡以半透明（opacity-60）呈现。

### 详情抽屉（只读）

点击推荐卡片打开抽屉，含四块：

1. **推荐摘要卡**：摘要 + 「建议行动：{...}」。
2. **优先级上下文卡**：得分 / 等级 / 排名 / 评分可用（是/否）/ 关键贡献维度徽标。
3. **AI 推荐理由卡**（仅当 AI 理由存在时）：蓝色 Alert「**以下内容为 AI 生成的推荐理由草案，仅供参考，不是正式项目决策。**」+ 正文 +「生成方：{provider} / {model} · {时间}」。
4. **来源信号卡**：source 徽标 +「不可用」（红）/「过期」（黄）+ summary；另附「警告（{n}）」黄底卡（code: message）。

> 注意：抽屉内**没有任何采纳/忽略/状态变更按钮——纯只读**。对推荐做状态变更（接受、忽略、转换等）与请求 AI 理由的接口存在（见下文「状态流转」），但当前页面不提供对应 UI。

## 状态流转

推荐状态机的合法流转如下（页面当前只展示状态徽标，不做流转操作）：

| 当前状态         | 可流转到                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------- |
| new 新推荐       | reviewing 审查中 / accepted 已采纳 / dismissed 已忽略 / snoozed 稍后处理 / expired 已过期 |
| reviewing 审查中 | accepted / dismissed / snoozed / converted 已转换 / expired                               |
| accepted 已采纳  | converted / expired                                                                       |
| dismissed 已忽略 | new / expired                                                                             |
| snoozed 稍后处理 | new / reviewing / accepted / dismissed / expired                                          |

## 操作步骤：审查推荐队列

1. **进入页面**：输入 URL `/pmo/ai-priority-recommendations`；无权限时显示「您没有 PMO 组合管理的访问权限。请联系管理员。」，加载失败显示「加载推荐数据失败，请稍后重试。」
2. **刷新推荐**：首次进入若队列为空，点右上「刷新推荐」；你会看到摘要 KPI 与推荐卡片更新。
3. **过滤队列**：按「严重」优先点击严重度过滤，或按状态过滤「已过期」等；右侧「共 N 条推荐」同步更新。
4. **审查单条推荐**：点击卡片打开详情抽屉，依次核对：摘要与建议行动 → 优先级上下文（得分/等级/排名）→（如有）AI 推荐理由（蓝色免责声明）→ 来源信号与警告。
5. **回到决策链路**：根据审查结论，到 [决策工作台](/help/articles/pmo.decisions) 发起议题，或在项目层面执行人工调整——推荐本身不会自动落地。

## 验证结果

- 空队列下显示绿色勾选空态文案「当前没有需要关注的推荐」；刷新后可看到摘要 KPI 与卡片。
- 过滤状态/严重度后列表与「共 N 条推荐」一致。
- 抽屉中 AI 理由卡带蓝色免责声明与 provider/model 信息；无 AI 理由时该卡不渲染。
- 整个页面不存在「一键采纳即生效」类操作（只读边界与人工审查红线）。

## 常见问题

**症状：队列一直为空。**
可能原因：所有项目状态良好，或尚未刷新推荐。
检查：是否点过「刷新推荐」。
修复：点「刷新推荐」重新生成；仍为空说明当前没有需要关注的推荐（正常）。

**症状：部分卡片显示「AI 失败/不可用/过期」。**
可能原因：AI 服务不可用、理由生成失败或理由数据过期。
检查：AI 状态徽标与「数据过期」徽标。
修复：刷新推荐；AI 失败时确定性评分与摘要仍可用，不影响人工审查。

**症状：想在抽屉里采纳/忽略推荐却找不到按钮。**
可能原因：当前页面只读——推荐状态变更与 AI 理由生成的接口存在，但页面未提供对应 UI（产品现状）。
检查：详情抽屉四张卡是否齐全。
修复：按现状把结论带入决策工作台人工处理；状态变更能力预计在后续版本开放 UI。

**症状：AI 理由与评分不一致。**
可能原因：评分是确定性模型，AI 理由是生成式草稿，二者口径不同。
检查：优先级上下文卡的得分/等级/排名。
修复：以确定性评分为基准、AI 理由为参考，人工判断。

## 安全与限制

- **AI 只建议、不自动执行**：所有推荐均为草案，需人工审查；页面无任何自动采纳/执行能力。
- **确定性基座**：推荐基于确定性评分模型（见 [优先级评分](/help/articles/pmo.priority-scoring)），AI 理由不参与评分计算。
- **只读页面**：抽屉无状态操作按钮；状态流转与 AI 理由接口存在但当前无 UI 入口。
- **过期处理**：数据过期的推荐整卡半透明并带徽标，不隐藏。
- **组织隔离**：推荐队列只含当前组织可见项目。

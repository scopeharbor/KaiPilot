# AI 能力参考：能力清单与边界

按能力维度查阅平台 AI 功能：每个能力做什么、入口在哪、依赖什么、边界在哪。全文贯穿一条红线——**AI 只建议、不自动执行**：AI 生成的任何内容都必须经人工确认才可能落库。

## 适用范围

- **适用角色**：所有角色；`org_admin` / `project_manager` 还需了解「哪些功能需要配置 AI 连接」。
- **所需权限**：各能力入口权限不同（`ai:trigger` 触发分析、`ai:confirm` + `project:create` 确认导入、`ai:connection:manage` 管理连接、`copilot:web_search:manage` 配置网页搜索），详见[权限参考](/help/articles/reference.permissions)。
- **适用版本**：v3。

## 开始之前

- 部分能力以[配置 AI 连接](/help/articles/ai.configure-ai-connections)为前置条件；未配置时可用的能力会明确标注「系统兜底」。
- 需要联网资料时，先确认组织是否启用网页搜索（默认关闭）。

## 能力总览

| 能力                                           | 入口                                                    | 前置条件                                                      | 关键权限                                                           | 是否需要人工确认                                   |
| ---------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------- |

| 澄清卡片 / 对话式澄清                          | `/ai-create` 流程内                                     | 已完成意图分析                                                | `ai:trigger`                                                       | 关键必答未答完不能进入就绪态                       |
| 全局 Copilot 侧栏                              | 顶栏 Sparkles 图标或工作台入口                          | 生产通道默认 live；演示模式无需连接                           | 读取权限由后端 readiness 评估                                      | 动作通道未接入，任何修改都不可自动执行             |
| OCR                                            | 设置 → AI 连接页「OCR 预览候选」；项目文件库 OCR 工作台 | 已启用 + 已设 key + 具备 OCR 能力的模型连接                   | `ai:connection:manage`                                             | 预览不落库；正式流程走文件库人工边界               |
| 外部网页搜索                                   | Copilot 侧栏 / AI 创建页开关                            | 组织启用 + provider 连接 + 按次同意                           | 写配置：`copilot:web_search:manage`                                | 结果仅作带引用的参考，不自动写入正式项目           |
| AI 用量与额度（team / enterprise）             | `/settings/ai-usage`（直达；个人版隐藏）                | `ai:usage:view`                                               | —                                                                  | 只读视图（当前呈现编译器运行摘要，见下文现状说明） |

## 能做与不能做

| 维度 | 能做 ✔                                                                                                                      | 不能做 ✘                                                                                                     |
| ---- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 生成 | 生成意图识别摘要、澄清问题、九模块项目草案（章程/WBS/任务/依赖/验收/资源/风险/里程碑/甘特预览）、Copilot 回答、OCR 预览提取 | 不创建正式项目、任务、WBS 或依赖——生成阶段零正式落库                                                         |
| 修改 | 草案审查页支持行内编辑与「确认导入（全部/所选）」，服务端**单事务**创建项目与任务                                           | 不绕过人工确认直接写正式表；「当前草案不可确认导入」「校验未通过，禁止确认导入」时强制阻断                   |
| 执行 | Copilot 给出建议、假设、澄清项与引用来源                                                                                    | **动作通道尚未接入**：所有动作卡片一律禁用预览态「预览不可用：动作通道尚未接入，不会自动执行任何修改」       |
| 数据 | 读取你授权范围内的项目上下文（页面语境 chips 披露「当前项目 #id · 页面 · 筛选 · 数据时间」）                                | 通用问答模式「不读取也不修改项目数据」；在 `/ai-create` 页为全局只读：不读取未导入草案，也不能修改或确认草案 |
| 演示 | 明确点击「查看本机演示（不写入任何数据）」后进入演示模式：回答来自固定示例，不读写任何真实数据                              | 生产通道错误**绝不静默切换**到演示；演示态有明确脚注「对话不会保存或修改任何项目数据」                       |
| 联网 | 组织启用、有权限、且你每**次**提问显式开启「允许本次使用网页搜索」后查询外部资料                                            | 默认完全关闭：关闭时 Copilot 与 AI 快速创建不会发起任何外部请求；外部来源仅作带引用的参考                    |

## 需要 AI 连接的功能清单

以下功能需要先在[配置 AI 连接](/help/articles/ai.configure-ai-connections)中保存带 API 密钥的连接：

| 功能                    | 连接要求                                                                                    | 未配置时的表现                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| AI 快速创建（草案生成） | 已启用的连接，且模型能力含 `project_draft` 或 `chat`                                        | 模型选择器显示「未配置草案模型，使用系统兜底」；草案审查卡标注「生成来源：Fallback / 离线结果」          |
| OCR                     | 已启用 + 已设 key + 模型具备 OCR 能力的连接                                                 | 「没有可用 OCR 模型」（演示环境种子只有停用样例，此为默认真实状态）                                      |
| 外部网页搜索            | 带 API 密钥的连接，并在[设置](/help/articles/ai.optional-web-search)中回填 Provider 连接 ID | 「未配置。请先在 AI 连接中保存一个带 API 密钥的连接，再回填连接 ID。」；此时即使启用开关「实际不会联网」 |
| Copilot 生产通道        | 默认 live 模式走真实回合端点                                                                | 演示环境提醒「回合通道未接入」，可经显式点击进入本机演示（只读）                                         |

## 网页搜索三重门

外部网页搜索必须**同时**通过三道门，缺一不可：

1. **组织启用**：设置 → 集成 →「Copilot 工具：外部网页搜索」总开关（默认关闭；写配置需 `copilot:web_search:manage`，仅组织管理员、项目经理）。
2. **按次同意**：每次提问时显式开启「允许本次使用网页搜索」——服务端锁定「必须」；Copilot 侧栏提交后自动复位，AI 快速创建按本次分析会话持续。
3. **后端门码**：额度 / 域名 / 超时 / 安全等检查，命中任一则以门码提示并**改用内部资料**：

| 门码                                                         | 界面含义                                           |
| ------------------------------------------------------------ | -------------------------------------------------- |
| `web_search_disabled`                                        | 组织尚未启用网页搜索；本次仅使用项目和内部知识     |
| `web_search_consent_required`                                | 若希望查询外部资料，请开启「允许本次使用网页搜索」 |
| `web_search_quota_exceeded`                                  | 今日组织搜索额度已用完；已改用内部资料             |
| `web_search_domain_blocked`                                  | 结果来自组织禁止的来源，未用于回答                 |
| `web_search_timeout`                                         | 外部搜索超时；已继续使用内部资料                   |
| `web_search_content_unsafe` / `web_search_permission_denied` | 内容安全未通过 / 缺少使用权限                      |
| `web_search_not_needed`                                      | 本次问题不需要外部资料                             |

> 边界：外部搜索使用隔离的 fixture/受控 provider，**真实 provider 接入需单独授权**；搜索结果仅作为带引用的参考，不会自动写入正式项目；每次调用单独计量并落低敏审计。

## 各能力要点

### AI 快速创建与草案审查

- **输入**：一句中文描述（10–4000 字），系统先识别项目类型、目标、交付物与缺失信息；输入框明确提示不要输入身份证、手机号、客户隐私等敏感信息。
- **澄清**：按「核心必答 → 专业补充 → Agent 追问」三阶段出卡，也可进入对话式澄清；关键必答未完成不能进入就绪态；「采用 AI 建议」「跳过」等操作只影响草案上下文。
- **生成**：九模块实时进度（项目章程/工作分解结构/任务清单/任务依赖/验收标准/资源建议/风险建议/里程碑/甘特图预览）；SSE 断线自动重连（最多 3 次、退避 1s/2s/4s），刷新页面从上次位置续传。
- **反幻觉校验（硬约束）**：校验规则为 `HL-001~HL-010`（自检阶段）与 `VE-001~VE-012`（验证阶段）；blocking 项显示「校验未通过，禁止确认导入」并禁止导入，warning 项弹「确认操作」对话框，info 项带 `ruleId` 提示；「自动修正差异」展示 before/after 与原因；不可确认时置信度上限压到 85%。
- **确认导入**：可「确认导入（全部）」或勾选「确认导入（所选 N）」；行内编辑仅暂存，点击确认导入才创建正式项目；未选中的内容按策略丢弃。
- **权限坑**：确认导入需要 `ai:confirm` **且** `project:create`，当前角色矩阵下仅组织管理员（及系统管理员通配）能真正导入；项目经理有 `ai:confirm` 但没有 `project:create`（见[权限参考](/help/articles/reference.permissions)）。

### Draft Layer 草案审查

- 面向 Compiler 产物的逐项审查：摘要 / Preview（只读投影，未写入正式项目）/ Diff（实体级增删改与冲突）/ 变更项接受/拒绝 / Dry-run & 校验 / 确认应用 / 放弃草案。
- **入口极窄**：没有导航项，当前唯一 UI 入口是 TRIZ 工作台「打开草案」链接；session 由后端从 Compiler Run 创建。
- apply 同样需要 `ai:confirm` + `project:create`；session 过期后全部操作禁用。

### Copilot 侧栏

- 新手/专业模式切换；页面语境披露（当前项目/页面/筛选/数据时间）；`@` 提及、`/` 命令、附件（PNG/JPEG/WebP/PDF，≤10MB，单回合 ≤5，仅项目页内可传）。
- 回答绑定提交时的页面快照；页面切换后可「使用当前页面重试」。
- 演示模式仅在你显式点击「查看本机演示（不写入任何数据）」后进入，脚注「回答来自固定示例，不会读写任何真实数据」，底部始终标注「AI 只给建议，任何修改仍需你在预览中确认」。

### OCR 现状（如实标注）

- 配置入口是 AI 连接页底部的「OCR 预览候选」（不是独立页面）：选择已启用且具备 OCR 能力的模型 + 上传图片（PNG/JPG/WebP，≤2MB）→「运行 OCR」→ 展示提取文本；**预览不落库、不写正式记录**。
- 正式 OCR 产品流（项目文件库 → OCR 识别 → 搜索索引/结构化提取/实体关联）走文件库的人工确认边界，详见 [OCR 配置](/help/articles/ai.configure-ocr)。
- **AI 用量页现状**：`/settings/ai-usage` 当前挂载「编译器运行摘要」（固定 run 0），实际使用中通常呈现「无法加载可观测摘要」或「暂无可观测数据」；新的用量接口已实现但前端尚未接入——该页当前不能展示组织真实用量，请勿将其视为成品视图。

## AI 红线速记

1. **只建议，不自动执行**：生成阶段零正式落库；正式项目/任务创建的**唯一**写入口是人工「确认导入」。
2. **草案必须经审查**：blocking 校验「禁止确认导入」不可绕过；warning 需确认对话框。
3. **反幻觉不可砍**：日期逻辑、依赖环路检测、规则校验、置信度评分全部存在（HL/VE 规则）。
4. **外部资料仅参考**：网页搜索外部来源带引用标记，与项目内部事实明确分区。
5. **组织隔离**：草案、连接、用量全部按组织过滤，跨组织一律 `RESOURCE_NOT_FOUND`。

## 验证结果

- 你能按表说出每个能力是否需要配置 AI 连接、是否需要人工确认。
- 你能说出「确认导入」的三个必要条件（`ai:confirm`、`project:create`、校验通过）以及当前哪些角色具备。
- 你能解释网页搜索三重门的顺序与任一门槛未通过时的界面表现。
- 你能正确描述 AI 用量页与 OCR 预览的当前真实状态（不是成品视图、预览不落库）。

## 常见问题

| 症状                                                          | 可能原因                                                                      | 检查                                                           | 处理                                                                    |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Copilot 说「没有可用的数据」/「我目前无法取得这个项目的数据」 | 未选择项目或上下文不可用（`context_unavailable`）                             | 页面语境 chips 显示的内容                                      | 重试，或告诉 Copilot 想查看的项目；仍失败时记录问题时间与 request id    |
| 模型选择器显示「未配置草案模型，使用系统兜底」                | 没有已启用且能力含 `project_draft`/`chat` 的连接                              | AI 连接列表的启用状态与模型能力                                | 配置并启用连接后重新生成；兜底草案会在审查卡标注「Fallback / 离线结果」 |
| 想用网页搜索但提示「组织尚未启用」或「需按次同意」            | 未过三重门                                                                    | 集成页开关状态；本次提问的开关是否开启                         | 组织管理员开启 + 配置 provider；每次提问显式开启开关；额度用完等次日    |
| 不确定某个 AI 能力是否可用                                    | 能力开关、模型连接、权限与授权门共同决定                                      | 需求清单与权限矩阵                                             | 以连接配置与权限为准，或咨询管理员；仍失败时记录能力名与 request id     |
| 项目经理找不到「确认导入」按钮入口                            | 确认导入需 `ai:confirm` + `project:create`，当前矩阵下 PM 缺 `project:create` | 对照[权限参考](/help/articles/reference.permissions)反直觉条目 | 由组织管理员确认导入，或请组织管理员显式附加权限                        |
| OCR 提示「没有可用 OCR 模型」                                 | 没有已启用 + 已设 key + OCR 能力的连接（演示种子只有停用样例）                | AI 连接列表                                                    | 新增并启用带 OCR 能力的连接与 API 密钥后重试                            |

## 安全与限制

- 所有 AI 输出均需人工确认才落库（V1 红线，零自动执行）；动作通道当前未接入，任何「修改」类建议都不可自动执行。
- 跨组织草案/连接/用量一律 404，不泄露存在性。
- 网页搜索默认关闭，真实 provider 接入需单独授权；外部结果仅作带引用的参考。
- AI 用量页、OCR 预览的现状以本文「如实标注」为准，不要按成品功能描述。
- 各套餐能力存在差异，具体以账单与组织设置为准。

# 限制、状态与概念参考

本页速查两类信息：**可核实的限量**（套餐配额、层级上限、批量上限、文件/OCR 限制、登录与 Webhook 限制等）与**状态语义**（任务/里程碑/投递/Skill/集成连接）。所有数字均来自当前版本可观察行为；未列入的数字不要假设存在。

## 适用范围

- **适用角色**：所有用户；`org_admin` 与 `system_admin` 用于核对配额与限制。
- **所需权限**：无（本页为参考）。
- **适用版本**：v3（free / team / enterprise）。

## 开始之前

- 本页「可核实」的含义：所列数字来自当前实现的校验器、种子与页面文案；**未列出的限制不等于不存在**，以服务端实际返回为准。
- 套餐差异：只有 free 套餐的配额数字是公开可核实的；team / enterprise 的能力与配额以账单与组织设置为准，本页不承诺具体数字。

## 套餐与组织配额

| 项目                  | 可核实的限制                                 | 说明                                                             |
| --------------------- | -------------------------------------------- | ---------------------------------------------------------------- |
| free 套餐：项目数上限 | `max_projects = 10`                          | 演示组织「我的默认组织」（plan free）的种子值                    |
| free 套餐：成员数上限 | `max_members = 20`                           | 同上                                                             |
| team / enterprise     | 以账单与组织设置为准                         | 本页不列出未核实的数字                                           |
| 组织成员角色          | `owner` / `admin` / `member` / `viewer` 四档 | 映射为规范角色见[权限参考](/help/articles/reference.permissions) |

## 项目与任务限制

| 项目                  | 可核实的限制                                                                                                                              |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 项目编码              | 后端：首字符必须是字母或数字，可含 `-` / `_`，最长 64 字符，**组织内唯一**（前端正则较宽松，以服务端校验为准，例如以 `_` 开头会收到 422） |
| 项目描述              | ≤ 2000 字符                                                                                                                               |
| 任务嵌套层级          | **≤ 3 级**（`MAX_TASK_DEPTH=3`；超出提示「子任务嵌套深度不能超过 3 级」）                                                                 |
| 任务名称 / 里程碑名称 | 1–255 字符（必填）                                                                                                                        |
| 任务/里程碑描述       | ≤ 2000 字符                                                                                                                               |
| 删除父任务            | 含活动（未删除）子任务的父任务不能删：单个删除 422「请先删除或移走该任务的子任务」；批量删除时该项单独失败                                |
| 回收站                | 只保留删除未满 30 天的任务，无永久删除；恢复超期 422「软删除已超过 30 天，无法恢复」                                                      |

> 注意：**任务嵌套（≤3 级）与 WBS 层级（≤20 层）是两棵不同的树**，上限口径不同，不要混写。

## WBS 与层级限制

| 项目       | 可核实的限制                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| WBS 总层数 | **≤ 20 层**（根节点 depth=0，最多再挂 19 层子级；新建提示「WBS 最多支持 20 层」；拖拽越深提示「移动后 WBS 将超过 20 层」） |
| 根节点     | 不可移动（「项目根节点不能移动」）、不可删除（「项目根节点不能删除」）、不可改名，且有「项目根」锁定徽章                   |
| 节点移动   | 不能移动到自身或其后代下；删除非根节点后，其直接子节点提升为一级节点并重排                                                 |
| 关联任务   | 只能关联当前项目的任务；一个任务只能关联一个 WBS 节点                                                                      |

## 批量操作与列表分页

| 场景                                                           | 可核实的限制                                                                                      |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 批量任务操作（批量编辑/重新指派/变更状态/移入回收站/批量恢复） | 单次 ≤ 100 项；页面提示「共 N 项 · 最多批量选择 100 项」；超出提示「一次最多选择 100 项任务。」   |
| 批量结果                                                       | 逐项独立事务、顺序执行、跨项部分成功；结果提示「已成功处理 X 项，失败 Y 项」，失败明细最多列 5 条 |
| 列表视图分页                                                   | 每页 20 / 50 / 100；后端 `perPage` 上限 100                                                       |
| 列表排序                                                       | 单列点击排序；Shift 多列排序最多 3 个字段（「列表最多支持三个排序字段」）                         |
| 甘特图数据量                                                   | 单项目任务约 1000 上限（100/页 × 10 页，V1 单项目任务上限）                                       |
| 日历视图                                                       | `perPage` 默认 200、上限 200                                                                      |
| 时间线                                                         | 每页 20、上限 50（「加载更多」）                                                                  |
| 看板                                                           | 每列 25 条/页                                                                                     |
| 项目列表                                                       | 每页 10                                                                                           |

## 文件、OCR 与 Copilot 附件

| 场景             | 可核实的限制                                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------- |
| 项目附件上传     | ≤ 10 MB（后端 `size: '10mb'`）                                                                                |
| OCR 支持格式     | 仅 **PNG / JPEG / WebP** 三种图片；**不支持 PDF 与 Office 文档**                                              |
| OCR 预览图片     | ≤ 2 MB；提示词 ≤ 500 字符                                                                                     |
| Copilot 输入附件 | 仅图片（PNG/JPEG/WebP）与 PDF，≤ 10 MB，单回合 ≤ 5 个；只能在项目页面内上传（提示「请在项目页面内上传附件」） |
| OCR 能力边界     | OCR 正文不直接写入知识库；下游为搜索索引/结构化提取/实体关联等候选                                            |

## AI 输入限制

| 场景                | 可核实的限制                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| AI 快速创建项目描述 | 10–4000 字（少于 10 字或超过 4000 字会触发校验）                                                     |
| 敏感信息            | 输入框提示「不要输入身份证、手机号、客户隐私等敏感信息；当前步骤只做意图分析与澄清」——仅提示，不拦截 |
| 草案进度游标        | 刷新页面后续传的进度游标只存低敏标识（sessionStorage，24 小时 TTL）                                  |

## 登录与安全限制

| 场景               | 可核实的限制                                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 登录锁定           | 同一 `email（小写）+IP` 连续失败 **5 次**锁定 **30 分钟**；锁定期内即使凭证正确也拒绝（`ACCOUNT_LOCKED`，「登录失败次数过多，账户已临时锁定，请 30 分钟后再试」） |
| OAuth state 有效期 | 10 分钟；过期提示「OAuth state 已过期」                                                                                                                           |

## 出站 Webhook 限制

| 项目     | 可核实的限制                                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 订阅名称 | 1–120 字符，仅限字母/数字/中文/空格/下划线/点/短横线/冒号/括号                                                                                        |
| 目标 URL | 8–2048 字符，必须 HTTPS、必须有 host、不得内嵌凭据                                                                                                    |
| 订阅事件 | 1–20 个；未知事件类型返回 `VALIDATION_ERROR`（422）；白名单为 `project.updated` / `task.created` / `task.updated` / `task.completed` / `risk.created` |
| 投递重试 | `maxAttempts = 5`，基础退避 1 秒指数增长；可重试分类 = timeout / network / rate_limited / server_error；HTTP 429 与 5xx 可重试                        |
| 投递状态 | 默认**不发起真实外发**（fixture 投递）；「订阅状态为『已配置』并不代表已投递事件」横幅是当前版本的预期状态                                            |

## 组织级网页搜索限制

| 项目             | 可核实的限制                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 每自然日搜索额度 | 设置范围为 1–10000，组织级计量；用量行显示「今日已用 {usedToday} / {limitToday}」        |
| 按次同意         | 服务端锁定「必须」：每次提问需显式开启「允许本次使用网页搜索」                           |
| 域名策略         | 准入制「允许域名（支持 `*.gov.cn` 通配）」+ 拒绝域名黑名单；**未配置允许域名时不会联网** |
| 单次结果上限     | `maxResultsPerQuery`（面板只读展示）                                                     |
| 场景开关         | 可分别允许用于通用 Copilot / AI 快速创建；默认关闭                                       |

## Skill Registry 限制

| 项目       | 可核实的限制                                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 列表分页   | 每页 20 条                                                                                                                                   |
| 基础优先级 | 1–10000（默认 100）                                                                                                                          |
| Skill Key  | 新建时可填，字母数字/短横线/下划线/点                                                                                                        |
| 内置 Skill | 8 个内置 Skill（状态 active、isBuiltin）不可编辑/删除/转移，可「复制」为组织副本                                                             |
| 双开关坑   | 前端开关默认开（页面能进），后端 `COMPILER_SKILL_REGISTRY_ENABLED` 默认关（列表接口返回 503 `FEATURE_DISABLED`）→ 常见真实状态是「载入失败」 |

## 通知限制

| 项目         | 可核实的限制                                                     |
| ------------ | ---------------------------------------------------------------- |
| 通知中心分页 | 每页 20 条                                                       |
| 未读徽章     | 顶栏铃铛徽章以 `99+` 封顶                                        |
| 通知归属     | 接收人私有：组织 + 接收人双重校验，只能操作自己的通知            |
| 演示环境     | 通知没有种子数据，需要先触发业务事件（指派任务、评论等）才能看到 |

## 状态速查

### 任务状态机

| 状态   | 语义     | 说明                                                                   |
| ------ | -------- | ---------------------------------------------------------------------- |
| 未开始 | 尚未开始 | 默认态                                                                 |
| 进行中 | 执行中   | 首次转入时回填实际开始时间（仅空时）                                   |
| 已完成 | 已完成   | 转入时回填实际完成时间（仅空时）；**重开**回 进行中 时清除实际完成时间 |
| 已阻塞 | 被阻塞   | 例如依赖未满足                                                         |
| 已暂停 | 暂停     | —                                                                      |
| 已取消 | 取消     | —                                                                      |

- 状态转换是**硬约束**：前后端同一张状态机表，非法转换返回 422「不能从 X 切换到 Y」；看板「移动到」非法项直接禁用；批量变更状态逐项校验，非法组合该项失败但其余项成功。
- 同状态转换幂等（不写审计）。
- 看板列与任务状态一一对应。

### 里程碑状态

| 状态            | 语义                                                 | 说明                                                  |
| --------------- | ---------------------------------------------------- | ----------------------------------------------------- |
| 未开始 / 计划中 | 表单可直选                                           | —                                                     |
| 已达成          | 只能**人工确认**达成（按钮显示「确认达成」并写审计） | —                                                     |
| 有风险 / 已逾期 | **系统推导展示态**，表单不可直选                     | 推导源是「未完成任务的最晚 end_date」，不依赖关键路径 |

### 出站 Webhook 状态

| 对象     | 状态                                                                                                                 | 语义                             |
| -------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 订阅     | `已配置`（active）/ `已停用`                                                                                         | 已配置不代表已投递（见上）       |
| 投递     | `待发送` / `发送中` / `成功` / `失败` / `已暂停`                                                                     | 失败可手动重试；已暂停时禁止重试 |
| 失败分类 | timeout / network / rate_limited / server_error / client_error / signature / config / disabled / exhausted / unknown | 前四类可重试                     |

### Skill 生命周期

`草稿`（draft）→ `评审中`（eval）→ `已激活`（active）；评审中可退回草稿；已激活可转 `已废弃`（deprecated）或 `质量告警`（quality_alert）；质量告警可回已激活/转已废弃；**已废弃无出口**。

### 集成 Provider 状态徽章

`待配置`（not_configured）/ `可连接`（ready）/ `预连接`（preconnected）/ `已连接`（connected）/ `未连接`（disconnected）/ `已停用`（disabled）/ `需重连`（needs_reauth）/ `检查失败`（check_failed）。Outlook/Slack/飞书/钉钉恒为 `待配置`（预连接模式，不交换 token 也不同步）；Google Calendar / GitHub / GitLab 配置环境变量后才进入真实连接流程。

## 验证结果

- 你能说出任务嵌套与 WBS 层级的两个不同上限，以及批量操作的单次上限。
- 你能说明登录锁定规则（5 次 / 30 分钟）与锁定期内正确密码也会被拒。
- 你能区分任务状态与里程碑状态中「可直选」与「系统推导」的差异。
- 你能解释「订阅已配置 ≠ 事件已投递」与「Skill Registry 页面能进但列表载入失败」两个状态之谜。

## 常见问题

| 症状                                                   | 可能原因                                                        | 检查                        | 处理                                           |
| ------------------------------------------------------ | --------------------------------------------------------------- | --------------------------- | ---------------------------------------------- |
| 不确定组织当前套餐能做什么                             | 套餐与功能开关信息分散                                          | 账单页与组织设置            | 以账单与组织设置为准；free 套餐数字见上表      |
| 批量操作提示「选择数量受限」                           | 超过 100 项上限                                                 | 已选数量                    | 分批执行（每批 ≤100）                          |
| 创建任务提示「子任务嵌套深度不能超过 3 级」            | 任务树超过 3 层                                                 | 当前任务层级                | 调整任务结构；需要更深的分解请走 WBS（≤20 层） |
| 提示「WBS 最多支持 20 层」/「移动后 WBS 将超过 20 层」 | WBS 深度超过 20 层                                              | 节点 depth（根为 0）        | 合并或重组节点                                 |
| 登录被拒「账户已临时锁定」                             | 连续失败 5 次触发 30 分钟锁定                                   | 最近登录尝试                | 等待锁定期结束；锁定期内正确密码也会被拒       |
| OCR 报「图片格式无效，请选择 PNG、JPG 或 WebP」        | 上传了 PDF/Office 或超限图片                                    | 文件格式与大小（≤2MB 预览） | 转为支持的图片格式后重试                       |
| Skill Registry 列表「载入失败」                        | 后端 `COMPILER_SKILL_REGISTRY_ENABLED` 未开启（前端开关默认开） | 环境配置中的开关            | 由组织管理员配置后端开关后重试                 |
| 外部协作者看不到某些状态/入口                          | `external_collaborator` 可见范围有限且无 `report:view`          | 项目成员角色                | 由项目负责人调整角色                           |

## 安全与限制

- 概念与状态以服务端模型为唯一事实，界面文案只是呈现。
- 本页只列可核实的限制；未列出的数字以服务端实际返回为准，不要假设存在。
- 本页不承诺 team / enterprise 的具体配额数字，以账单与组织设置为准。
- 投递、真实 OAuth、真实 OCR 等外部动作受功能开关与授权门约束：当前版本默认 fixture/预连接，相关「未启用」状态是预期行为而非故障。

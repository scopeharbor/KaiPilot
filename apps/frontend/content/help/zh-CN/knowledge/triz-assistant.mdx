# AI-TRIZ 助手：对话式分析与工具推荐

AI-TRIZ 助手（页头副题「确定性 TRIZ 工具路由 · 只建议，不自动执行」）用自然语言描述你的 TRIZ 问题，助手给出**工具路由推荐**：推荐哪个 TRIZ 工具、建议做什么、还需要补充什么信息。推荐结果来自确定性路由与（可用时）AI 增强——无论是否接入真实模型，你都得到一套**只建议、不执行**的分析路径。

## 适用范围

- **适用角色**：需要 `triz_assistant:view`——授予**组织管理员、项目经理、成员、只读观察者**；**外部协作者无此权限**（直接输入 URL 会看到无权限提示）。
- **所需权限**：`triz_assistant:view`（使用助手）；`ai:trigger`（AI 增强分析；不可用时自动降级为确定性建议）。
- **适用版本**：免费版、团队版、企业版。
- **进入路径**：`/projects/{项目ID}/triz/assistant`（当前无侧栏入口；可从项目头「AI-TRIZ 助手」链接进入，或直接输入 URL）。

## 开始之前

- 准备一个可描述的问题，例如「如何改善质量但降低速度？」——输入框 placeholder 即此示例。
- 无需配置 AI 连接也可使用：未连接或服务失败时，助手显示降级警告并退回确定性建议（不影响路由推荐本身）。
- 了解边界：助手只做**推荐与对话**，不自动执行任何 TRIZ 分析或写入；具体分析请到推荐的工具页面手动操作。

## 操作步骤

### 步骤 1：发起对话

1. 打开 `/projects/{项目ID}/triz/assistant`；你会看到三段式布局：左侧「助手会话」、右侧主区（推荐 TRIZ 工具 / 建议操作 / 需要补充信息）、底部输入区。
2. 在输入区（Textarea，placeholder「描述你的 TRIZ 问题，例如：'如何改善质量但降低速度？'」）输入问题。
3. 按 <kbd>Enter</kbd> 提交（<kbd>Shift</kbd> + <kbd>Enter</kbd> 换行）；按钮显示「提交」，分析中变为「分析中…」。

### 步骤 2：阅读推荐结果

提交后主区依次生成三类内容：

1. **推荐 TRIZ 工具**：只展示置信度为 high/medium 的路由决策卡，每张卡包含「目的地」+ 置信度徽标（`高置信`/`中置信`/`低置信`/`降级`）+ reason + 警告徽标（如有）。目的地标签包括：`澄清卡片` / `矛盾矩阵` / `技术矛盾分析` / `物理矛盾分析` / `IFR 可视化` / `功能分析图` / `资源分析` / `进化趋势` / `推荐理由` / `创新工作台` / `决策中心` / `Draft 预览`。
2. **建议操作**：按钮形式展示建议动作；来源已过期（isStale）时按钮禁用（title 显示说明）。
3. **需要补充信息**：澄清问题卡 + quickOptions 快捷选项按钮——点击快捷选项会把内容填入输入框，供你补充后再次提交。

> [!IMPORTANT]
> **推荐卡片与建议操作按钮当前仅作展示，不可点击跳转**（没有绑定跳转逻辑）。例如推荐「矛盾矩阵」后，你需要自己打开 `/projects/{项目ID}/triz/contradiction-matrix` 继续分析；「技术矛盾分析」「物理矛盾分析」「IFR 可视化」「推荐理由」等目的地目前**没有独立的前端路由**，卡片仅提示方向。请阅读卡片 reason 后按你自己的判断手动导航——不要期望点击卡片会自动跳转。

### 步骤 3：处理降级与警告

- 页面出现「AI 增强已降级为确定性建议（{原因}）」警告时，说明 AI 通道不可用（未配置模型/服务错误/预算超限等），当前返回的是**确定性路由建议**——仍可使用，但不会包含 AI 增强内容。
- 会话卡带 `降级`/`正常` 徽标与警告徽标；左栏「暂无会话记录」为空态。
- 常见警告码与含义：

| 警告码（中文）                                   | 含义                                     |
| ------------------------------------------------ | ---------------------------------------- |
| 来源不可用 / 来源已陈旧 / 来源无权限             | 项目来源读取问题                         |
| 上下文已截断 / 信息不足 / 意图模糊               | 输入不足以给出高置信路由，会请求补充信息 |
| 目标不可用 / 目标不可访问                        | 推荐目的地不可达                         |
| AI 已降级 / 幻觉检测 / AI 预算超限 / AI 服务错误 | AI 通道问题；幻觉检测命中时结果只作参考  |
| 操作已过期 / 功能已禁用 / 跨组织已阻断           | 操作时效/功能/组织边界问题               |

### 步骤 4：在推荐工具页面继续（手动交接）

按卡片 reason 选择继续路径，例如：

- 推荐「矛盾矩阵」→ 打开 `/projects/{项目ID}/triz/contradiction-matrix` 查看参数热力图与候选原理。
- 推荐「创新工作台」→ 打开 `/projects/{项目ID}/triz-workbench` 把候选路径加入方案篮子。
- 推荐「决策中心」→ 打开 `/projects/{项目ID}/triz-decision-center` 集中审查与决策。

助手本身不代替任何工具页的执行——所有分析动作都在对应页面人工完成。

## 验证结果

- 提交问题后，主区出现含 reason 的推荐工具卡（仅 high/medium 置信度展示）与建议操作块。
- 信息不足时出现澄清问题卡；点击 quickOptions 后内容填入输入框，可再次提交。
- 未接入 AI 时看到「AI 增强已降级为确定性建议（{原因}）」警告，推荐仍可用。
- 左栏会话记录随提交增加，卡片显示 intentSummary（截断 60 字符）与正常/降级徽标。
- 外部协作者打开本页看到无权限提示（`triz_assistant:view` 未授予）。

## 安全与边界限制

- **只建议，不自动执行**：助手不触发任何分析运行、不写任何数据；所有工具操作需人工在工具页确认。
- **卡片展示边界**：推荐工具卡与建议操作按钮不可点击；「技术矛盾分析」「物理矛盾分析」「IFR 可视化」「推荐理由」无独立路由——文档如实地告诉你：请按 reason 手动导航。
- **确定性兜底**：AI 不可用时退回确定性路由建议并明示降级原因，不会静默假装 AI 结果。
- **权限边界**：外部协作者无 `triz_assistant:view`；AI 增强受 `ai:trigger` 控制。
- **组织隔离**：会话与来源严格按项目/组织隔离；跨组织内容被阻断并提示。

## 常见问题

**症状：点击推荐工具卡没有反应。**
可能原因：卡片仅作展示（无跳转逻辑）。
检查：卡片上的 reason 文字。
修复：按 reason 手动打开对应工具页（如 `/projects/{id}/triz/contradiction-matrix`）；这是当前版本的设计边界，不是故障。

**症状：页面顶部出现「AI 增强已降级为确定性建议（{原因}）」。**
可能原因：AI 通道不可用（未配置模型/服务错误/预算超限）。
检查：警告码与原因文本。
修复：在「设置 → AI 连接」确认连接状态；无需 AI 时可直接使用确定性推荐。

**症状：推荐区为空，只有澄清问题卡。**
可能原因：输入信息不足/意图模糊，或推荐置信度低于 high/medium（低置信不展示）。
检查：「需要补充信息」卡的问题列表。
修复：利用 quickOptions 或补充更多上下文后重新提交。

**症状：外部协作者打开助手页看到无权限提示。**
可能原因：`triz_assistant:view` 未授予 external_collaborator（设计如此）。
检查：账号角色。
修复：使用组织管理员/项目经理/成员/只读观察者账号，或由组织管理员调整授权。

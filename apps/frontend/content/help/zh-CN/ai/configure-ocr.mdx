# 配置与使用 OCR 识别

OCR 把图片中的文字提取为可编辑文本。本文介绍如何在「设置 → AI 连接」页面底部配置 **「OCR 预览候选」**，并用它验证单个图片的文字提取效果。

请特别注意两点边界：

- **OCR 预览不写正式记录**：运行 OCR 只返回提取文本用于核对，不会创建正式的 OCR 记录或自动进入任何项目数据。
- **提取结果必须人工核对**：OCR 文本不会自动被当作真实项目事实使用。

## 适用范围

| 项目         | 说明                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------- |
| **适用角色** | 需要 `ai:connection:manage` 权限（通常为组织管理员、系统管理员，或已被授予该权限的项目经理/成员） |
| **入口**     | 「设置 → AI 连接」（`/settings/ai-connections`）页面底部的「OCR 预览候选」面板                    |
| **前置依赖** | 至少一条**已启用、已设 API Key、模型勾选了 OCR 能力**的连接                                       |
| **适用版本** | free / team / enterprise                                                                          |

> [!IMPORTANT]
> OCR 配置入口**就是** AI 连接页的「OCR 预览候选」，没有独立的 OCR 配置页面。若下拉框中显示「没有可用 OCR 模型」，说明当前没有满足条件的连接，按下方步骤 2 补配置。

## 开始之前

1. 确认你拥有 `ai:connection:manage` 权限（能进入并管理「设置 → AI 连接」）。
2. 准备一条用于 OCR 的模型连接：专用 OCR 模型准确度更高，建议不要与对话模型混用（配置方法见《配置 AI 连接》）。
3. 准备一张待识别图片：支持 **PNG / JPEG / WebP**，大小 **≤ 2MB**，文字清晰、方向正常、光线充足。

图片质量直接影响识别结果，上传前按此清单检查：

| 检查项 | 合格标准               | 不合格示例              |
| ------ | ---------------------- | ----------------------- |
| 格式   | PNG / JPEG / WebP      | PDF、BMP、HEIC          |
| 大小   | ≤ 2MB                  | 扫描件未压缩的 RAW      |
| 清晰度 | 文字边缘锐利           | 抖动拍摄、低分辨率截图  |
| 方向   | 正向（0°/180° 内可读） | 横躺 90° 的表格         |
| 光照   | 均匀无阴影遮挡         | 窗口反光、背光拍摄      |
| 版面   | 单面完整入镜           | 合同页被裁掉页码/金额行 |

## 操作步骤

### 步骤 1：确认或新建带 OCR 能力的连接

1. 打开「设置 → AI 连接」（`/settings/ai-connections`）。
2. 检查是否已有一条 **已启用、已设 Key** 的连接，且其模型勾选了「OCR」能力（在连接的编辑弹窗 → 模型区 → 能力复选中确认）。
3. 没有则新建：点击 **「新增连接」**，填写显示名称、协议与 Base URL，粘贴 API Key，在「添加模型」中勾选能力 **OCR**，保存并回到列表。
4. 对新连接执行 **「测试」**，确认返回「已连通」；若连接未启用，先勾选「启用供应商连接」再测试。

![AI 连接列表页：连接卡片之下是「OCR 预览候选」面板，包含「OCR 模型」下拉、图片上传与「运行 OCR」按钮；无满足条件的模型时下拉显示「没有可用 OCR 模型」。](assets/ai-connections-list.png)

### 步骤 2：在「OCR 预览候选」中选择模型

1. 滚动到「AI 模型连接」列表页底部，找到 **「OCR 预览候选」** 面板。
2. 打开 **「OCR 模型」** 下拉：候选项来自**已启用 + 已设 Key + 模型勾选 OCR 能力**的连接，格式为 `{连接} / {模型}`（例如「OCR 连接 / gpt-ocr-v1」）。
3. 选择本次预览要使用的模型。无任何候选项时，下拉显示「没有可用 OCR 模型」，回到步骤 1 补配置。

> [!NOTE]
> 下拉中不会出现未启用、未设 Key 或未勾选 OCR 能力的连接，这是防止误用失效模型的保护机制。

### 步骤 3：上传图片并运行 OCR

1. 点击图片输入区域（文件选择器，accept 为 png/jpeg/webp），选择一张清晰图片，例如一张竖版拍照的合同页。
2. 点击 **「运行 OCR」**（运行期间按钮显示「识别中...」）。
3. 等待提取完成，结果区显示：`{provider} · {model} · {latency}ms · Token N`，下方是提取出的文本块（pre 格式，保留段落顺序、数字与标点）。

### 步骤 4：人工核对提取结果

1. 逐字段对照原图检查：文字是否完整、数字（金额、日期、编号）是否与图片一致、排版顺序是否正确。
2. 本面板只做**预览核对**，不提供落库动作；确认可用后，把该连接作为后续 OCR 能力的模型基础。

## OCR 模型选择建议

「OCR 预览候选」的候选规则与选择策略：

| 维度             | 建议                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| **候选条件**     | 仅「已启用 + 已设 Key + 模型勾选 OCR 能力」的连接进入下拉；不满足任一条件的连接不会出现，这是防误用保护 |
| **专用 vs 混用** | 专用 OCR 模型准确度更高；对话模型混用 OCR 可能因能力不匹配导致识别质量差                                |
| **延迟与成本**   | 结果区显示 `{latency}ms` 与 Token 消耗，可据此对比不同模型的实际表现                                    |
| **文字语言**     | 中文、数字、表格类图片优先选择对中文/版面优化过的模型；目录卡会显示知识截止与模态信息辅助判断           |

验证模型是否适合 OCR 的两种方法：

1. **测试连接**：在连接卡片点「测试」，确认连通性与 Token 统计正常（未启用连接测试会提示「请你先启用之后才可以测试」）。
2. **预览试跑**：在「OCR 预览候选」选择该模型，用同一张图对比不同模型的提取结果与延迟。

## 验证结果

- 选择正确的 OCR 模型后，「运行 OCR」返回 `{provider} · {model} · {latency}ms · Token N` 与提取文本。
- 提取文本与图片内容一致（关键数字、日期人工核对通过）。
- 上传不合规文件时页面给出明确错误（见常见问题）。
- 预览结束后，项目与正式业务数据没有任何变化（OCR 预览不落库）。

## 限制与安全边界

- **不落库**：OCR 预览接口只返回候选数据，不写正式 OCR 记录，也不会自动把文本写入项目、任务、WBS 或搜索索引。
- **人工确认**：提取结果不被视为「真实项目事实」，必须人工核对后才能用于后续流程。
- **权限**：配置与预览均在 `ai:connection:manage` 门控下；无权限用户看不到该面板。
- **组织隔离**：图片与提取内容受组织级数据隔离约束，跨组织不可见。
- **格式与大小**：仅支持 PNG/JPEG/WebP 且 ≤ 2MB；不支持 PDF 与其他格式。
- **能力边界**：当前平台提供的是 OCR 模型配置与单图提取预览；完整的 OCR 文件处理产品流程尚未开放。真实 OCR 供应商接入属于外部动作，需另行授权。

## 常见问题

| 症状                                                 | 可能原因                                       | 检查与修复                                                |
| ---------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------- |
| 下拉显示「没有可用 OCR 模型」                        | 无满足「已启用 + 已设 Key + OCR 能力」的连接   | 检查连接的启用状态、Key 是否已设、模型是否勾选「OCR」能力 |
| 提示「请选择 OCR 模型和图片」                        | 未选模型或未选图片就点「运行 OCR」             | 先选择模型与图片再运行                                    |
| 提示「图片过大，请选择 2MB 以内的 PNG、JPG 或 WebP」 | 图片超过 2MB                                   | 压缩或裁剪后重试                                          |
| 提示「图片格式无效，请选择 PNG、JPG 或 WebP」        | 文件格式不支持（如 PDF、BMP、HEIC）            | 转换为 PNG/JPEG/WebP 后重试                               |
| 提示「图片读取失败」                                 | 文件损坏或读取异常                             | 换一张图片重试；仍失败则记录页面提示                      |
| 识别文本乱码或缺失                                   | 图片模糊、文字过小、横竖方向错误，或模型不适配 | 更换清晰图片、修正方向后重试；必要时换专用 OCR 模型       |
| 识别结果与图片明显不符                               | 模型能力与任务不匹配                           | 在「配置 AI 连接」中核对模型能力，改用专用 OCR 模型       |

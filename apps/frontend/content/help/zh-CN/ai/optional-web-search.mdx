# 可选 Web 搜索能力

AI 模型自带知识有截止时间；需要时效性信息时，平台提供可选的**外部网页搜索**。它**默认关闭**，且被三重条件严格把关——这一能力不会把外部内容当作项目事实，也不会自动写入任何正式数据。

## 三重门机制

外部网页搜索必须同时满足以下三个条件才会真正联网：

| 门             | 内容                                                                                            | 说明                                                                                   |
| -------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **① 组织启用** | 组织管理员在「设置 → 集成设置」的「Copilot 工具：外部网页搜索」面板中启用并完成搜索服务连接配置 | 写入需 `copilot:web_search:manage`；未配置搜索服务连接时即使开关打开**实际也不会联网** |
| **② 按次同意** | 每次提问时你显式打开使用页面上的「允许本次使用网页搜索」开关                                    | Copilot 侧栏提交后**自动复位**；AI 快速创建的分析会话内持续生效                        |
| **③ 后端门码** | 每次调用由后端检查配额、域名策略、内容安全等并返回门码                                          | 任一条件不满足即不联网，改走内部资料                                                   |

> [!IMPORTANT]
> 三重门是安全红线：组织未启用、未按次同意、额度耗尽、域名被禁、超时或内容不安全时，系统**不会**绕过门控使用外部资料。页面上也会明确标注「外部搜索使用隔离的 fixture/受控 provider；真实 provider 接入需单独授权」。

## 适用范围

| 项目         | 说明                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| **配置**     | 组织管理员/系统管理员（`copilot:web_search:manage`）在 `/settings/integrations` 配置 |
| **查看**     | 所有登录用户可读配置状态（低敏投影：已启用 + 打码的 provider 标签）                  |
| **使用**     | 具备 Copilot 或 AI 快速创建入口权限的用户，按次同意                                  |
| **生效场景** | 通用 Copilot 问答 / AI 快速创建（由场景开关控制）                                    |

## 开始之前

- 配置前需先在「设置 → AI 连接」保存**一条带 API 密钥的连接**，把连接 ID 回填到「搜索服务连接」；面板提示「请先在 AI 连接中保存一个带 API 密钥的连接，再回填连接 ID。」（附「管理 AI 连接」跳转链接）。
- 明确组织的域名策略：允许域名采用**准入制**（每行一个，支持 `*.gov.cn` 通配），拒绝域名采用黑名单。
- 明确每日搜索额度（1–10000 次/自然日），额度按组织共享。

## 配置说明（组织启用门）

「Copilot 工具：外部网页搜索」面板（`/settings/integrations` 页尾）字段：

| 配置项                   | 说明                                                              | 示例               |
| ------------------------ | ----------------------------------------------------------------- | ------------------ |
| **启用外部网页搜索**     | 总开关，默认**关闭**；关闭时面板徽章显示「默认关闭」              | 开 / 关            |
| **搜索服务连接**         | Provider 连接 ID（来自 AI 连接）；留空 = 未配置，**实际不会联网** | `web-search-prod`  |
| **每自然日搜索额度**     | 1–10000，按自然日重置                                             | `500`              |
| **允许域名（准入制）**   | 每行一个，支持 `*.gov.cn` 通配；不配置任何域名 = 不会联网         | `*.gov.cn`         |
| **拒绝域名（黑名单）**   | 每行一个，命中即不采用该来源                                      | `example-spam.com` |
| **允许用于通用 Copilot** | 场景开关：控制 Copilot 侧栏可使用                                 | 开                 |
| **允许用于 AI 快速创建** | 场景开关：控制 AI 快速创建的分析可使用                            | 开                 |

面板固定展示「按次同意：必须」「单次结果上限：{N}」与用量「今日已用 {usedToday} / {limitToday}」。

操作流程：配置后点 **「保存设置」**（有改动才可点击），成功显示「已保存（HH:MM:SS）。provider 密钥不会出现在响应中。」；失败显示「没有管理网页搜索设置的权限」或「保存失败，请稍后重试」。无权限的只读用户看到「当前状态：已启用（provider 已配置）/ 已启用（provider 未配置，实际不会联网）/ 未启用」+「每次使用需按次同意。」+「你可以在使用页面的开关处控制每一次提问是否允许联网搜索。」

> [!WARNING]
> API 密钥只存储在后端加密服务中，配置页面不显示、也不要求填写密钥明文。

## 使用侧行为（按次同意门）

- **Copilot 侧栏**：打开「允许本次使用网页搜索」→ 提交；**提交后开关自动复位**，下一次提问需要再次开启。
- **AI 快速创建**：在意图输入区打开同名单开关，按本次分析会话持续生效（提交后不自动复位）。
- 双方开关文案：关闭时「允许本次使用网页搜索」；开启后「本次允许联网搜索：可能发送你问题涉及的主题；组织域名策略与额度适用；外部资料仅作参考，不会直接写入正式项目」。

## 后端门码对照表

联网结果会通过门状态条反馈（外部资料不可用 → warning；已使用 → success）。门码文案为系统原文：

| 门码                           | 显示的文案                                           | 含义               |
| ------------------------------ | ---------------------------------------------------- | ------------------ |
| `web_search_disabled`          | 组织尚未启用网页搜索；本次仅使用项目和内部知识。     | 门①未过            |
| `web_search_consent_required`  | 若希望查询外部资料，请开启「允许本次使用网页搜索」。 | 门②未过            |
| `web_search_quota_exceeded`    | 今日组织搜索额度已用完；已改用内部资料。             | 门③：额度          |
| `web_search_domain_blocked`    | 结果来自组织禁止的来源，未用于回答。                 | 门③：域名黑名单    |
| `web_search_timeout`           | 外部搜索超时；已继续使用内部资料。                   | 门③：超时          |
| `web_search_content_unsafe`    | （内容安全拦截，无公开文案）                         | 门③：内容安全      |
| `web_search_permission_denied` | （权限拒绝，无公开文案）                             | 门③：权限          |
| 成功                           | 已使用外部网页搜索（结果带引用来源）。               | 三重门全部通过     |
| `web_search_not_needed`        | 本次问题不需要外部资料。                             | 未触发联网（正常） |

> [!NOTE]
> 当门码为成功态时，消息区附注「外部来源带引用标记，仅供参考；项目内部事实仍以项目数据为准。」——引用不等于背书，决策请二次核实。

## 验证结果

- 配置面板保存成功并显示「已保存（HH:MM:SS）」；只读用户能看到当前状态与「按次同意：必须」。
- 三重门全部打开后提问时效性问题，消息区出现「已使用外部网页搜索（结果带引用来源）」。
- 任一门未过时，门码文案如实显示（如「今日组织搜索额度已用完；已改用内部资料。」），回答继续使用内部资料。
- 任何情况下，搜索结果不会自动写入正式项目数据。

## 限制与安全边界

- **默认关闭**：不配置即不启用；AI 依赖模型自身知识，时效性回答可能过时。
- **按次同意必须**：服务端锁定每次调用需用户同意，无法配置为「永久允许」。
- **每次调用单独计量并落低敏审计**。
- **真实 provider 需授权**：当前外部搜索使用隔离的 fixture/受控 provider；接入真实联网 provider 属于外部动作，需另行授权。
- **不影响核心能力**：搜索为可选增强；草案生成、Copilot 问答在未启用搜索时照常工作。

## 常见问题

| 症状                                                | 可能原因                         | 检查与修复                                                                   |
| --------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------- |
| 提问时效性问题没有来源                              | 网页搜索未启用或未按次同意       | 检查组织启用状态与「允许本次使用网页搜索」开关；不在项目页内时仅内部资料可用 |
| 开启开关后仍提示「组织尚未启用网页搜索」            | 门①未过                          | 由有 `copilot:web_search:manage` 权限的管理员在集成设置启用                  |
| 提示「今日组织搜索额度已用完」                      | 组织当日额度耗尽                 | 次日重置；或由管理员调高「每自然日搜索额度」（1–10000）                      |
| 提示「结果来自组织禁止的来源」                      | 命中拒绝域名                     | 与管理员核对拒绝域名清单；该结果未用于回答                                   |
| 提示「外部搜索超时」                                | 搜索服务响应超时                 | 已自动回退内部资料，重试一次即可                                             |
| 面板显示「已启用（provider 未配置，实际不会联网）」 | 未回填搜索服务连接 ID            | 先在 AI 连接保存带密钥的连接，回填连接 ID                                    |
| 无权限修改设置                                      | 缺少 `copilot:web_search:manage` | 只读查看状态；联系组织管理员授权                                             |
